## 📌 О проекте

«**Оно тебе надо**» — аукцион необычных вещей, отвергнутых обществом или критиками в момент их создания, но со временем ставших культовыми шедеврами мировой культуры:
- 🎬 **Фильм** режиссёра, который бросил киношколу после первой лекции (Пол Томас Андерсон).
- 📖 **Книга** на тысячу страниц об одном дне дублинского рекламного агента без знаков препинания («Улисс» Джеймса Джойса).
- 🎨 **Картина**, которую, казалось бы, повторит даже пятилетний ребенок, а на деле — шедевр абстракционизма Василия Кандинского.

Главная цель проекта — воплотить замысел дизайнеров в валидном, доступном и легко поддерживаемом коде, полностью соответствующем строгим критериям автотестов Яндекс Практикума.

## 🛠 Что было сделано в проекте

В процессе работы над проектом был выполнен полный цикл верстки и интеграции:

1. **Семантическая структура HTML5**:
   - Шапка сайта заключена в тег `<header>` с навигационным меню `<nav>`, списком ссылок `<ul>` и векторным логотипом в формате `.svg`.
   - Контактная информация структурирована с помощью семантического тега `<address>` с активными кликабельными ссылками `tel:` для звонка и `mailto:` для электронной почты.
   - Главная часть страницы заключена в `<main>` и логически разбита на независимые секции `<section>`: `cover`, `lots`, `about`.
   - Каждая карточка каталога лотов оформлена семантическим тегом `<article class="card">`, обернутым в `<a class="card-link">` для доступности всего пространства карточки для клика.
   - Подвал размечен тегом `<footer>`, содержащим повторный блок `<address>`, навигацию и список социальных сетей со ссылками.

2. **Модульная организация стилей CSS3**:
   - Стили разделены на три отдельных файла:
     - `fonts/fonts.css` — регистрация локальных шрифтов семейства `Raleway` (Regular и Bold) в форматах `.woff` и `.woff2` через директивы `@font-face`.
     - `styles/global.css` — сброс стандартных стилей браузера (CSS Reset), нормализация базовых отступов, списков, ссылок и заголовков.
     - `styles/style.css` — компонентные стили по БЭМ для всех блоков лендинга.

3. **Современные механизмы раскладки (CSS Grid & Flexbox)**:
   - **CSS Grid** применен для:
     - Шапки сайта (`.header`): трехколоночная сетка `grid-template-columns: 1fr min-content 1fr;` с центрированием логотипа и прижатием меню и адреса к противоположным краям.
     - Секции «Об аукционе» (`.about`): двухколоночная сетка `grid-template-columns: 240px 1fr;` с зазором `column-gap: 24px;`.
     - Подвала (`.footer`): симметричная трехколоночная сетка `grid-template-columns: 1fr min-content 1fr;`.
   - **CSS Flexbox** применен для:
     - Списка карточек лотов (`.lots__card-list`): многострочный контейнер с `display: flex; flex-wrap: wrap; gap: 25px;`. Каждая карточка имеет `flex-grow: 1; min-width: 334px;`, благодаря чему лоты автоматически и равномерно заполняют всю ширину ряда.
     - Внутренней структуры карточек (`.card`): `flex-direction: column; justify-content: space-between;`, гарантирующей, что название лота всегда зафиксировано сверху, а текстовое описание прижато к нижнему краю независимо от его длины.
     - Навигационных меню шапки и подвала, а также списка иконок социальных сетей.

4. **Методология БЭМ (Блок-Элемент-Модификатор)**:
   - Имена всех классов написаны в строгом соответствии с БЭМ (Classic):
     - Блоки: `header`, `cover`, `lots`, `card`, `about`, `footer`, `address`, `overlay`, `bet-button`.
     - Элементы: `header__menu`, `header__logo`, `lots__heading`, `lots__card-list`, `card__title`, `about__text`.
     - Модификаторы: `card_type_film`, `card_type_book`, `card_type_picture`, `header__link_active`, `aligned-text_left`, `aligned-text_center`, `aligned-text_right`.
   - Переиспользуемые независимые блоки:
     - `.address` — универсальный блок контактной информации, используемый и в шапке, и в подвале без дублирования стилей.
     - `.overlay` — затемняющий слой (`background-color: rgba(0, 0, 0, 0.6);`) с абсолютным позиционированием (`inset: 0`), используемый на обложке и во всех карточках лотов.

5. **Ювелирная работа с типографикой (Pixel-Perfect)**:
   - Заголовок секции Cover («ОНО ТЕБЕ НАДО») разбит на 3 строки со смещением:
     - 1-я строка: выравнивание по левому краю (`aligned-text_left`);
     - 2-я строка: выравнивание по центру (`aligned-text_center`);
     - 3-я строка: выравнивание по правому краю (`aligned-text_right`).
   - На заголовке применен широкий трекинг `letter-spacing: 30px;`.
   - **Компенсация краевого символа**: в CSS свойство `letter-spacing` добавляет отступ после каждого символа, включая последний, из-за чего крайняя правая буква «о» смещалась бы от правого края контейнера. С помощью служебного класса `.no-letter-spacing` (`letter-spacing: 0;`) для последней буквы правый край заголовка идеально совпадает с направляющей сетки макета.
   - Стилизована кнопка ставки: прозрачный фон, белая рамка 1px, строчные буквы, локальный шрифт Raleway, выверенные внутренние паддинги.

## 🧪 Автоматическое тестирование

В репозитории настроен автоматический запуск тестов при каждом пуше и создании тегов через GitHub Actions:
- **Файл конфигурации**: `.github/workflows/tests.yml`
- **Тестовый раннер**: `Yandex-Practicum/test-project-action@v1` с параметром `project: 'ono-tebe-nado-ad'`.
- **Статус тестов**: все проверки разметки, доступности, стилей и соответствия макету успешно пройдены (`Passed`).

## 🚀 Локальный запуск

Для просмотра проекта на локальном компьютере не требуется сборщиков или пакетных менеджеров:

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/ZeNoS55/ono-tebe-nado-ad.git
   cd ono-tebe-nado-ad
   ```

2. **Откройте `index.html` в браузере**:
   - Двойным кликом по файлу `index.html` в проводнике;
   - Либо с помощью расширения **Live Server** в VS Code для живой перезагрузки при редактировании:
     ```bash
     # При установленном live-server:
     npx live-server .
     ```
